# Stage 08 — STL AI Creator Assistant
Open /dashboard/stl-bot, /dashboard/ai-assistant or /ai-builder. Unified seven-mode workspace: website, product, social, campaign, analytics, growth, chat. Existing URLs retained. The previous UI-specific chatbot and AI Builder are superseded by this read-only workspace; old chat API accepts compatible messages but uses only the latest user message and no autonomous tools. Other agent automation routes and Supabase edge functions remain independent and are not covered by this quota. Review them in Stage 10 before enabling production automation. No auto posting, emailing, web fetching, account edits or publishing.
## Setup
Apply earlier migrations and 20261126180000_creator_ai_budget.sql in staging. Configure either OPENAI_API_KEY (direct) or AI_GATEWAY_API_KEY (correct Gateway URL), server only. Enable CREATOR_AI_ENABLED=true after staging checks. Model fixed to gpt-4o-mini; one bounded call with 1200 output tokens and 22-second provider timeout. Prompt length capped. No additional Vercel entrypoint, dependencies or paid Vercel plan required. Model inference is separately billed by provider. Configure provider spend limits separately. Global 1000 accepted attempts/month default (creator_ai_budget.monthly_cap; 0 disables); change only after founder review. Free 3, Pro 30, Business 100, legacy Enterprise 100 shared monthly attempts. Atomic quota lock across accounts. Quotas reset UTC month; accepted failed requests count; no automatic retry or refund. The Stage 08 migration is necessary for the global cap; existing builder RPC preflight fails closed without its budget table.
## Data
Only user-provided brief and optional own-account aggregate counts go to model. No raw customer records, credentials, IDs, emails, or analytics events are included in prompts. Do not input sensitive data. Actual analytics use exact counts, null on source error, not fabricated zeros. Metrics are recorded event counts, not unique visitors or conversion rates. Rule-based tips available without model calls. AI-generated text is plain text, reviewed by user. Website config is allowlisted and schema validated; temporary sessionStorage keyed to user; explicit import into Studio, then existing authenticated save/publish and premium checks. No automatic live changes. No chat history is persisted by new UI.
## Validation
Run automated tests and production build, then verify authenticated account switching, DB quota concurrency and cap, provider test requests with spending control, no key exposure, errors/429, metric accuracy, draft handoff on mobile, free and premium publishing, and legacy routes. Other automation APIs still require separate usage/security audit. Production migrations and live activation not performed.
