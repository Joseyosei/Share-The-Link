# Stage 06 — Monetisation
Free £0 / 8% platform fee / 3 PDF products / 3 AI page-builder requests per UTC month. Creator Pro £7 monthly or £56 yearly / 2% / 30 products / 30 builder requests. Business £17 or £136 / 0% / 100 products / 100 requests. Enterprise legacy supported at Business limits. These are proposed prices; Stripe processing fees, taxes and other channels are separate. No live payments enabled. Existing external product listings are not counted; limits count all digital drafts and published products, no delete yet. Existing products stay visible after a downgrade; new creation blocked at cap. Existing discount codes remain valid; new ones require paid tier. The AI allowance counts accepted builder requests including fallback results; other assistant routes and legacy Supabase functions are not yet metered. Basic links are unlimited in shared UI catalog; existing independent limits must be audited. No blanket server enforcement of all legacy UI features claimed.
