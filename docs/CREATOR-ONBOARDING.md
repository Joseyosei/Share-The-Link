# Stage 04 — Creator onboarding
Dashboard launchpad replaces the original setup checklist. Goals persist per authenticated account. Recommendations use existing free themes and existing features; no external AI provider or new subscription cost. Completion is calculated from actual profile and link state, selected goal and recorded copy action. Copy is not evidence of sharing. Activation is verified by SQL using page username and an active link. Historical first activation is first observed by the feature, not backfilled. No automatic template application or destructive changes.

## Runtime recovery
PGRST202 for sync_creator_onboarding and PGRST205 for founder_events mean the connected Supabase schema is missing the relevant migrations or its PostgREST cache is stale. Apply both migrations in order to the correct project after verifying staging, then run NOTIFY pgrst, 'reload schema'; and refresh. A successful Vercel deployment does not apply SQL migrations. If syncing is unavailable the launchpad persists goal/copy state in account-scoped browser storage, explicitly labels it local, and retries pending changes after connectivity is restored. No local data is counted in founder analytics until synced. If storage is blocked the UI warns that unsynced progress is session-only. No new API function.
