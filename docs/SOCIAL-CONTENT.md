## Security and lifecycle
Server-generated state hashed, bound to authenticated user/provider, consumed once, expires after 10min. Google PKCE; other web flows use provider confidential client + state. AES-256-GCM with user/provider associated data. Never return tokens to browser. No arbitrary URL fetching; no redirects on provider requests. Token refresh stored before fetching media; database lease protects concurrent refresh, generation guards disconnect/reconnect. Disconnect deletes cached content and tokens locally, attempts remote revocation on TikTok/Google; Instagram requires user to revoke in account settings. Do not claim remote revocation where it fails. Provider deauthorization webhooks, data deletion callback, key rotation, full audit and explicit privacy-policy review remain release blockers. Expired public cache hidden. No public content before explicit publishing. Imported content may disappear when deleted or no longer among recent posts after next sync. No production data changes.
