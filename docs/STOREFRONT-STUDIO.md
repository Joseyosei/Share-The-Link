# Stage 07 — Storefront Studio
Open Dashboard > Appearance > Open website builder, or /dashboard/website. Six curated layouts (two free, four premium), searchable category gallery, section drag handles and keyboard/move buttons, custom accent and optional platform branding removal, phone/tablet/desktop-width preview. Public site at /site/:username, distinct from original /:username and /shop/:username. Existing links/profile/appearance are not overwritten; links and active digital products are read at render time. Existing website theme editor and existing template gallery remain independent. Gallery is a first-party curated catalogue, not a third-party paid marketplace.
## Persistence and permissions
Apply prior migrations and then 20261126160000_storefront_studio.sql to staging. Drafts and published snapshot stored separately, server-authenticated identity and service-role-only table/RPC. Optimistic revision conflict prevents stale overwrites. Free users may draft/preview all designs but publishing a premium layout, custom accent, or hidden branding requires server-verified paid tier. Free layouts can publish even if Stripe is unavailable. Published premium designs are grandfathered after downgrade until next publish; no automatic destructive redesign. Unpublish always allowed. Public API returns published configuration and only public profile/link/catalogue fields, never drafts or files. Section content is plain text; no arbitrary HTML/CSS. Existing legacy theme permission enforcement is not changed.
## Tests and release
Verify migration on isolated Supabase project, direct table/RPC denial, cross-user writes, stale revision, free/premium publish, public read before/after unpublish, responsive browser layout, drag keyboard/touch, URL filtering, account switching and existing profile behaviour. Product section links to test-only digital shop; does not enable payments. Preview falls back to current profile/links if schema unavailable; save/publish require database. No production database modifications. No new standalone Vercel functions.
